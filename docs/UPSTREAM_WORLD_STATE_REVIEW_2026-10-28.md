## P0 handoff

The highest-impact source hazards are **Gen4 honey-tree index 21 accepted beyond 0–20**, **Gen3 RTC invalid time and partial parse**, **negative roamer IV bit contamination**, **Roamer3.IVsGlitch temporary writes to live memory**, **reroll partial-state mutation**, **HoneyTreeValue.Group rewriting SubTable**, and **Hall of Fame SetEntries lacking a 50-entry count guard**. Implementer must reproduce these in isolated synthetic fixtures and enforce fail-closed wrappers; none authorizes save export.

## Integration and licensing

Use pinned official Core behind generation-specific immutable projections and per-document identity checks. No upstream modal Save handler is safe to adopt without independent transaction, provider and byte-allowlist tests.
