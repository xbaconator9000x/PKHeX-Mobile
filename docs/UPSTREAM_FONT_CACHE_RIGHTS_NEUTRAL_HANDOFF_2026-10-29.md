# Rights-neutral editor: font licence and cached game-art cutover (2026-10-29)

**Decision / implementation handoff.** Continue the already compiling **PKForge MAUI editor + official PKHeX.Core**, not another rewrite. The latest implementation PR #73 closed the runtime downloader/installer routes and verified diagnostic APK permissions. The next release-enabling work is to neutralize **bundled assets and persistent cached art** before publishing an APK. This is a source audit, not a claim of redistribution approval, Android device certification, safe Save As, or full desktop parity.

## Newly isolated release blockers

### P0-FONT: NDS12 is explicitly non-commercial, not a GPL-cleared font

At the exact PKForge pin, [\`Resources/Fonts/NDS12-license.txt\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Resources/Fonts/NDS12-license.txt) explicitly says **Creative Commons Attribution–NonCommercial–ShareAlike**, and [\`NDS12-readme.txt\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Resources/Fonts/NDS12-readme.txt) says the font is based on the Nintendo DS system font and requires accompanying archive files on redistribution. [\`PKForge.App.csproj\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/PKForge.App.csproj#L30-L43) includes **all** \`Resources/Fonts/*.ttf\`, so this is a concrete bundled asset, not a hypothetical future download. GPL's commercial-use/distribution freedoms cannot be claimed for a bundled NC-licensed font. Do not ship it as part of a GPL-only rights-cleared APK without a separate legally valid permission and review; **replace it** for the first preview.

Replacement is not merely deleting \`NDS12.ttf\`: [\`MauiProgram.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/MauiProgram.cs) registers \`NDS12.ttf\` under \`PixelUI\`, and [\`PixelFont.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/PixelFont.cs) opens \`NDS12.ttf\` from the package and caches it for Skia. Both routes need a deliberately chosen **documented redistributable font** or a verified system-font fallback; test text layout and Japanese/Unicode behavior. \`MPLUSRounded1c-*.ttf\` files are also packaged, but the inspected upstream Fonts directory does not itself contain a corresponding M PLUS licence file; independently establish exact font-version rights and notices rather than assuming they are cleared.

### P0-CACHE: GameArt can redisplay previously cached unreviewed artwork even after a clean rebuild

Pinned [\`Services/GameArt.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/GameArt.cs) uses \`FileSystem.CacheDirectory\` and the stable \`AssetVersion = "v10"\`; \`GetBySlugAsync\` returns an existing \`gameart-v10-*.png\`, \`gamehero-v10-*.png\` or \`gamelogo-v10-*.png\` **before** checking whether a package asset exists. Pinned [\`HomePage.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/HomePage.cs#L1043-L1058) calls \`GameArt.GetIconAsync\` when binding a save card. PR #73's [offline adapter](../scripts/pkforge_offline_preview.py) has no GameArt guard. Thus removing unreviewed art from a **new** APK does not, by itself, prevent an upgraded diagnostic installation (\`org.pkforge.app.debug\`) from displaying cached unreviewed art. This is a source-derived rights/preview containment gap, **not a reproduced device leak**.

Fast fix: for diagnostic preview, make all three public GameArt getters return null/neutral *before any cache lookup*, and keep the HomePage text/icon fallback functional. Never merely bump \`AssetVersion\` as the primary control; it only hides known old cache names and does not enforce policy. A cache-clear/migration is optional hygiene, not a substitute for the guard. Confirm no parallel game-art loaders bypass this service.

### P1-UX: disabled sprite pack reports misleading success

Pinned [\`HomePage.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/HomePage.cs#L984-L1003) treats \`SpritePackDownloader.CountMissing()==0\` as “Already downloaded: every sprite is on this device”. PR #73 changes \`CountMissing()\` to return zero for offline diagnostics. This creates a false success message in the preview UI, not a network-permission bypass. Hide the download option or explicitly say “Unavailable in offline preview”; preserve truthful status without reopening downloads.

### P1-UX/RIGHTS: hidden Bad Apple route remains wired

[\`AboutPopup.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/AboutPopup.cs) still calls \`BadAppleEgg.PlayAsync\` on the Konami sequence; [\`BadAppleEgg.cs\`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/BadAppleEgg.cs) opens \`badapple/frames.bin\` and \`badapple/audio.m4a\`. Upstream [asset attribution](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Resources/UI/ATTRIBUTION.md) identifies separate commercial song/video authors. Removing these package files should make the route fail gracefully, but the fastest clean preview should also remove/hide the trigger and exclude the audio, frames and any old derived caches from deliverables.

## Shortest safe implementation path (implementation stream owns code)

1. **One coherent asset cutover:** in the temporary PKForge adaptation, remove NC NDS12 and all unreviewed \`MauiAsset\` / icon / splash / font entries, supply independently licensed neutral replacements, update \`MauiProgram\` + \`PixelFont\` + any \`PixelUI\` consumers, and disable \`GameArt\` reads before cache access. Remove hidden media routes and misleading sprite-pack UI.
2. **Fast synthetic tests first:** NC-font rejection; cache prepopulation denial; missing media/neutral text fallback; duplicate and implicit assets; source freeze; writer denial; original URI hash unchanged. Re-run pinned Core and Android diagnostic compile. An empty or self-approved asset inventory is not legal clearance.
3. **Distribution boundary:** independently verify each retained asset/font hash, permission, attribution, transitive dependency and corresponding GPL source; attest actual APK, not just csproj; only then publish a clearly labelled **preview-only** APK and test cold/upgrade installs on Android. Do not distribute upstream art, ROMs, saves or secrets.
4. **Safe editing later:** authenticated retail read with same-version desktop oracle, then independently tested Save As. No ROM-hack writes until versioned layout profiles pass negative and positive tests. Do not claim desktop parity.

**Audit scope:** this document and its paired \`docs/PARITY_*\` gate document only; no application, tests, scripts, dependencies, workflow or README changes. README first line remains \`# This is a test.\`.
