## Safety/architecture disposition

The mobile adapter must distinguish **decoded game string**, **raw field bytes**, **localized UI label** and **filesystem export name** as four different representations. None authenticates the save's game/layout. A raw string editor must be scoped to an immutable document fingerprint, PKM identity, field offset and pinned Core revision; no change should be applied to the source PKM during preview. For future exports, validate both semantic values and exact permitted byte deltas, including hidden terminators/trash and checksums. A successful legality result alone never authorizes saving an unsupported ROM hack.

**Desktop parity:** the WinForms raw hex/glyph/trash editor exists in the cited source. Neither current PKHeX-Mobile's read-only Android party/box display nor MAUI's existence of a text editor proves equivalent coverage or safe behavior. **Licence:** maintain GPL-compatible source and attribution for imported code; do not copy fonts, sprite atlases, copyrighted game art, ROMs or private saves as test fixtures. The reviewed files were inspected, not imported.

**Handoff:** [PARITY_TEXT_ENCODING_GATES_2026-10-28.md](PARITY_TEXT_ENCODING_GATES_2026-10-28.md) defines deterministic positive/negative tests and acceptance artifacts. Audit-owned documentation only; the implementation watchdog owns `src/`, `tests/`, build and workflows. Keep all writing disabled until independent same-version desktop fixtures, authenticated save layouts, staged Save As/readback and rollback gates pass.
