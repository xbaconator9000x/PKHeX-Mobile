**Important source delta:** The exact release [R `MyItem9a.cs` lines 10–20](https://github.com/kwsch/PKHeX/blob/bfe89c74a3f5265805e364b79bc04ad38ebbc5ea/PKHeX.Core/Saves/Substructures/Gen9/ZA/MyItem9a.cs#L10-L20) describes 0xBB80 and has no pouch-unlock flag accessor; the newer [C lines 10–48](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.Core/Saves/Substructures/Gen9/ZA/MyItem9a.cs#L10-L48) describes 0xBC00 with a trailing 0x80 region and nine named unlock bits. This is a **source revision difference**, not proof that a particular save on disk uses either layout. Do not implement later-source behavior against Core 26.10.18 without independent fixtures.

Verified source-level sizes: SV `MyItem9.ItemSaveSize = 3000`, Z-A `MyItem9a.ItemSaveSize = 3000`, both inventory records are 0x10 bytes; therefore their 3000-record array is 0xBB80 bytes. The newer Z-A source documents an additional 0x80-byte region. These are code declarations, not observed fixture lengths.

## Cross-format parity and Android architecture decision

The desktop [inventory editor](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.WinForms/Subforms/Save Editors/SAV_Inventory.cs#L21-L47) exposes per-game item constraints and flags, while PKForge supplies a richer Android bag UI and presets but not independently certified write safety. MAUI supplies a mobile editor with source-level session, quantity and remote-injection hazards. **Decision for this subsystem:** implement an original, immutable, Android-independent read-only bag projection backed by exact pinned Core, with stable numeric IDs and per-game typed flags. Reuse design ideas only after testing, not mobile fork code or sprites. Keep edits/export disabled until independent desktop fixtures and complete transactional write gates pass.

Required read-only fields: save identity and Core revision; pouch type; numeric item ID; quantity; display label as nonauthoritative; flags and padding where defined; slot/index semantics; unavailable/unknown field state; full source SHA-256. Preserve zero-count records and Gen9 obtained flags rather than filtering them. A future write command must carry exact document revision, authenticated game/layout profile, requested item ID and pouch, expected original record, allowed changed-byte scope, staging/backup/reopen result and independent same-version desktop comparison.

**Licensing:** Official [Core project](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.Core/PKHeX.Core.csproj#L10-L21) declares GPL-3.0-or-later; [PKForge LICENSE](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/LICENSE) contains GPLv3 text. MAUI's use of named sprites and Forge's cache paths do not establish third-party image redistribution rights. No commercial art or fork assets were copied. Preserve source notices, GPL obligations and separate artwork provenance.

## Limits, prioritization and evidence rules

This pass inspected the 17 version-compared official files plus MAUI inventory, PKForge session, bag UI, preset model/store/tests, mobile inspector and upstream project/licence metadata. This is not a comprehensive class-by-class desktop inventory, full dependency/asset audit, or runnable upstream build. **All 38 gates remain not-run**; earlier source audits and device/write-safety gates remain open.

P0 implementer order: (1) isolate session identity and refuse MAUI-style detached/live injection; (2) stable IDs, capacity/count validation and immutable drafts; (3) guard whole-bag `CleanIllegalSlots` and Gen9 absent-item zeroing; (4) reject unauthenticated pouch/item combinations; (5) explicitly version Z-A 26.10.18 versus later 0x80-byte flags; (6) prove exact backup/rollback and independent desktop readback. For each executed gate record source SHA, package SHA, test command, fixture rights/provenance, original/output SHA-256, changed-byte map, format/version, provider/API, observed status and failure evidence. Do not call a same-Core synthetic test independent desktop parity.

**Ownership:** Audit docs only. Implementation watchdog owns source, tests, dependencies and workflows. README first line remains `# This is a test.` No save-write permission is granted; Milestones 0 and 1 remain open.
