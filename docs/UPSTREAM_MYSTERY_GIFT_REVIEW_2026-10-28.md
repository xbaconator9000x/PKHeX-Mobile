## Architecture and safety disposition

- **Engine:** keep official pinned PKHeX.Core as the sole canonical game-format parser. Distinguish parsed gift files, stored save cards, received history, archive distribution metadata and generated Pokémon as **different trust domains**. Neither card parse success nor Pokémon legality authenticates a retail/hack save layout.
- **Read-only first:** immutable projection should carry `save fingerprint + exact game/context + storage slot + card type + card bytes digest + received-flag state`; never retain mutable Core objects in Android view models. Explicitly label unsupported generations and unavailable history.
- **Mutation later:** gift delivery, card replacement and item grant need immutable preview, occupied-slot refusal, all-or-none transaction, original-byte backup, exact revision recheck, staged write, independent reparse and block-level diff. A user confirmation cannot bypass unknown hack identity.
- **Licensing:** upstream code is GPL-governed (see official [PKHeX licence](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/LICENSE) and [PKForge licence](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/LICENSE)); PKHeX MAUI's exact source and image rights still need per-file verification. Neither a code licence nor the existence of embedded/gallery event data establishes redistribution rights for game assets, distribution card collections, fonts or sprites. Do **not** import or publish those assets; retain attribution and GPL source obligations for any eventual permitted code adaptation.
- **Coverage:** Forge's [F:MysteryGiftInboxTests.cs L9–47](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/tests/PKForge.Engine.Tests/MysteryGiftInboxTests.cs#L9-L47) and [F:EventDatabaseMetadataTests.cs L78–114](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/tests/PKForge.Engine.Tests/EventDatabaseMetadataTests.cs#L78-L114) are synthetic test *source*, not tests executed here.
