## Architecture and licence disposition

**Recommended implementation direction:** retain the original PKHeX.Core dependency and Android-first immutable read-only presentation. Model *save-container identity*, *PKM entity type*, *game/context*, *Core revision*, *transfer policy* and *source byte hash* as distinct typed facts. An entity parser success, bank metadata, legal verdict or matching filename never authenticates a ROM-hack save. A transfer is an explicit transformation with a full before/after field diff and an independent desktop oracle, not a hidden step of Save As. Do not use Forge's backward reflection downgrade or MAUI's shared static editor state as default behavior.
