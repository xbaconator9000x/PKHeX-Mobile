## Architecture and source/licence disposition

Keep the current independent Android UI and official pinned Core adapter as a **provisional** architecture: Forge's world services demonstrate useful per-game capability gating and rollback-on-failure patterns, but its hack-risk confirmation and direct export patterns cannot be reused as safe authorization. MAUI's menu and Gen9 handlers have source-level omissions requiring tests before adaptation. Desktop's source revision is newer than the port's package and must not be treated as a same-version oracle.

No upstream code, DLL, font, artwork, ROM, commercial asset or save file was copied. Every potential import requires individual rights and source review, especially MAUI's local AutoMod/Injection references and Forge's mixed artwork glob patterns. GPL obligations apply to source distribution, but do not by themselves clear unrelated asset rights.

**Execution status:** none of the acceptance tests in the companion pass F matrix were executed by this source-only audit. No code was changed. See [pass F acceptance gates](PARITY_EDITOR_DISPATCH_GATES_2026-10-28.md). The audit index and older findings are not superseded.
