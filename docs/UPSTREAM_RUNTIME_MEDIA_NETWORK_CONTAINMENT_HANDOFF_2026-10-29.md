## Newly verified integration exposure: runtime content escapes the packaged-media inventory

**P0-M1 (preview candidate boundary, source-level):** The APK inventory hashes packaged `assets/`, `res/` and media ZIP entries, but the adapted PKForge app also fetches visual media **at runtime**, outside that inventory. Merely stripping `MauiAsset` includes or approving the APK ZIP does not create a self-contained, rights-reviewed *offline preview*.

Exact pinned entry points:

1. [`SpriteService.WarmHome`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/SpriteService.cs#L195-L243) downloads HOME images from the PokeAPI/sprites GitHub path. [`WarmShowdown`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/SpriteService.cs#L258-L277) downloads animations; [`DownloadPackFileAsync`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/SpriteService.cs#L580-L614) streams further remote assets. These are app-private caches, not APK ZIP entries.
2. [`ItemArt.GetAsync`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/ItemArt.cs#L33-L72) fetches item PNGs by slug; it already offers a [programmatic neutral placeholder](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/ItemArt.cs#L89-L130) that should be reused.
3. [`SpritePackDownloader`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/SpritePackDownloader.cs#L9-L45) advertises a ~600 MB archive from PKForge releases and optional add-ons; [`FetchAddOnsQuietlyAsync`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/SpritePackDownloader.cs#L81-L114) can fetch in the background. SHA-256 of an upstream ZIP verifies *bytes*, not redistribution permission or the candidate's offline guarantee.
4. [`PokeparkSpriteService`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/PokeparkSpriteService.cs#L12-L20) fetches PMDCollab media; the [upstream README](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/README.md) identifies its art as CC BY-NC 4.0. Pokepark is not necessary to prove party/box/nickname preview.
5. [`PKForge.App.csproj`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/PKForge.App.csproj) separately bundles `BadApple/*`, SteamGridDB game artwork, PKHeX sprite/ribbon/wallpaper trees, Showdown, Team Lumi forms and fonts. [`ATTRIBUTION.md`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Resources/UI/ATTRIBUTION.md) records mixed provenance, including commercial Bad Apple media. These packaged items remain covered by the earlier rights-review gate.

**Interpretation:** downloading media is not automatically equivalent to distributing it in an APK, and this audit does not make a legal conclusion about a particular remote image. The concrete problem is that an allegedly **offline, rights-neutral preview candidate** would still initiate unreviewed media requests and cache/display uncontrolled assets. It also creates network, privacy and test-reproducibility differences. No observed Android download or infringement is claimed.

**P0-M2 (installer boundary, source-level):** [`AppUpdateService.CheckAsync`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/AppUpdateService.cs#L30-L34) already refuses update *checks* when the package ends `.debug`; preserve this good guard. But [`DownloadAndInstallAsync`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/AppUpdateService.cs#L80-L130) and [`StartAndroidInstall`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/AppUpdateService.cs#L157-L208) have no corresponding `.debug` refusal. The source declares `REQUEST_INSTALL_PACKAGES` and `UPDATE_PACKAGES_WITHOUT_USER_ACTION`. Normal Home UI reaches install only after an offered update, so **this is a defense-in-depth bypass, not a proven normal-user exploit**. A preview-only APK should not have an independent installer at all.

**P1-M3 (placeholder closure):** the existing [`ThemeLogo`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Services/ThemeLogo.cs) already returns null on missing logo; [`PokedexPicker`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/PokedexPicker.cs#L100-L124) catches absent bundled sprite/artwork at its icon-cache boundary; [`PixelFont`](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Views/PixelFont.cs#L15-L50) has system-font fallback. Do **not** rewrite these without a failing test. Verify *all* reachable preview routes render usable text/neutral geometry when optional media is absent; replace required app icon/splash with original rights-cleared assets rather than deleting them.

## Implementation handoff: minimal release path

1. Keep the pinned PKForge editor, official Core and all write barriers. Add a **diagnostic-flavor media policy at the network service boundary**, not only hide UI buttons: `SpriteService` HOME/Showdown/pack, `ItemArt`, `SpritePackDownloader`, `PokeparkSpriteService` and update installer must return offline/disabled without a request. Remove install-package permissions in diagnostic manifest; ideally require no `INTERNET` permission in preview-only flavor. If the core UI truly needs connectivity, document a narrow allowlist and explicit consent; no silent background fetch.
2. Strip or replace unreviewed bundled media, including `BadApple/*` and SteamGridDB/game art, with original neutral app icon/splash and text/shape placeholders. Keep copyright notices for any genuinely retained third-party material. Avoid broad deletion of source/classes: preserve the compiled editor and runtime navigation.
3. Run source-level/host tests with injected HTTP/installer spies **plus** inspect merged Android manifest and packaged assets. Re-run existing preview/containment/session tests, #71 full input freeze and official-Core Android compile. No new downloader should bypass the policy via a direct `HttpClient`.
4. After independent licence/dependency/corresponding-source approval, publish a clearly labeled **preview-only debug APK**. Install on Android emulator and physical device; test offline cold launch, party/box/nickname preview/discard, Back/rotation, zero original writes and zero unexpected HTTP/installer requests.
5. Only then authenticate real retail saves against the pinned desktop oracle and implement distinct Save As with independent reopen/byte diff. Keep ROM hacks and missing desktop editors explicitly unsupported until their own fixtures and gates pass.

**Desktop parity still absent/uncertified:** full Pokémon field/moves/origin/ribbons/memories, legality suggestions, trainer, bag, Pokédex editing, Mystery Gift, event flags, batch, Showdown import/export, generation transfers, generation-specific world editors, localization/accessibility. The source UI may expose some of these; none is certified as safe Android desktop-equivalent. Do not claim full parity or a 30-hour release guarantee.

**Audit ownership:** only `docs/UPSTREAM_*` and `docs/PARITY_*`; no changes to application, source, tests, dependencies, workflows or README. No ROMs, personal saves, artwork binaries, secrets or APKs. Findings are source-level unless a CI/test run is explicitly cited.
