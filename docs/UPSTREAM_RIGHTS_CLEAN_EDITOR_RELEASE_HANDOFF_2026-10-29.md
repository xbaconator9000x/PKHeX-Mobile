## Two new narrow release blockers (not regressions in already-passing tests)

**P0-R1: no rights-reviewed artifact handoff exists.** [`verify_packaged_media_review`](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/466f2d17cccd15825402e3edc33896854bd2ab1a/scripts/pkforge_artifact_attestation.py#L239-L294) is a useful exact path/hash allowlist comparator, but [the actual CI attestation invocation](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/466f2d17cccd15825402e3edc33896854bd2ab1a/.github/workflows/pkforge-official-core-probe.yml#L209-L226) never calls it or supplies an independently approved review. The report intentionally sets `rights_review_complete=false` and `redistribution_authorized=false`; no APK is uploaded. A matching allowlist **alone** still cannot establish legal permission: the comparator accepts strings in `license`, `reviewer`, `provenance` and `approved`, with no trusted reviewer or external evidence. Require a separately reviewed licence/provenance manifest and corresponding-source/notice closure before any APK upload. Treat internal-only test delivery as distribution unless a qualified rights review says otherwise.

**P0-R2: the prebuild source freeze does not cover all inputs that can change the APK.** [`source_tree_manifest`](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/466f2d17cccd15825402e3edc33896854bd2ab1a/scripts/pkforge_artifact_attestation.py#L303-L324) hashes only selected text suffixes under `src/`; it excludes `Resources/*.png`, `Resources/BadApple/*`, and the two `external/` gitlink working trees. [`check_pins`](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/466f2d17cccd15825402e3edc33896854bd2ab1a/scripts/pkforge_artifact_attestation.py#L51-L57) checks Git HEAD, not working-tree cleanliness. Thus a post-freeze image change, or an uncommitted change to external source, can leave the frozen-source comparison green. The APK ZIP is hashed **after** packaging, so its changed bytes will be reported, but are not compared to a prebuild trusted asset snapshot. Reproduce by freezing a synthetic tree, changing `src/PKForge.App/Resources/AppIcon/pkforge.png` or an `external/` file, then verifying the old freeze; it should currently pass. This is a provenance coverage limitation, **not evidence of tampering**. Freeze all resolved build inputs (including media and external source), or prove clean immutable checkouts and compare an exact pre/post asset manifest; fail on new, missing or modified inputs.

## Rights-specific evidence: remove before any candidate APK

The pinned [PKForge.App.csproj](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/PKForge.App.csproj) bundles `Resources/BadApple/*`, `Resources/GameArt/*`, `GameHero/*`, `GameLogo/*`, `Showdown/*`, `UI/lumi/*`, `Pokepark/park/*`, PKHeX sprite/artwork/ribbon/wallpaper trees, icons, splash and fonts. Its [ATTRIBUTION.md](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Resources/UI/ATTRIBUTION.md) explicitly identifies the Bad Apple easter egg's commercial song/video authors, game art/logos separately from CC-BY icons, and mixed provenance for custom forms. **GPL code does not confer blanket rights over these media.** Exclude Bad Apple and game/character art by default; use original text/shape placeholders for the first installable editor. CC-BY / GPL / MIT media may be considered individually only with matching file-level evidence, attribution and notices. Check NuGet transitive licence records, embedded resources and GPL corresponding source separately. Do not ship ROMs, private saves, secrets or signing keys.
