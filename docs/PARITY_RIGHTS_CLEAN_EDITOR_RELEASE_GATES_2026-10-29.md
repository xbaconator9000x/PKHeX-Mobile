### Suggested execution order

**First PR:** RC-01–08 and RC-14 together (asset-neutralization + full input closure + release gate) while keeping existing preview and write-denial tests green. **Second PR:** RC-09–11 device/provider and retail oracle. **Third PR:** RC-12 distinct Save As. RC-13 is a living parity ledger, not permission to defer P0 work.

Existing synthetic tests and passing CI are evidence of the behaviors they exercise, **not** substitutes for the proposed gates. No real ROM, private save, game art, keys, credentials, or APK signing material should be committed.
