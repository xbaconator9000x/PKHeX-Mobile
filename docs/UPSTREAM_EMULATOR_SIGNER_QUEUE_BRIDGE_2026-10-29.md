1. **Reuse #83 or explicitly retire it; never create a competing emulator implementation.** Rebase its useful emulator runner on fresh main, discard its legacy queue and old workflow copies, and make a single reviewed exact `PORT-APK` claim only if implementation requires one. The claim must identify its actual branch, PR number and immutable base SHA; rerun `validate` and owner-specific `next --resume`.
2. Preserve main's source-freeze, permission, cloud/D2D backup, negative-media, APK selector and `apk-signer` gates. In the same ephemeral job use `$RUNNER_TEMP/pkforge-selected-apk.json` to obtain the **only** install path; rerun `--verify-selection` and `pkforge_apk_signature_gate.py` immediately before `adb install -r "$apk"`. Record the same SHA-256 and signer fingerprint with the install result. No `find` fallback, no arbitrary unsigned APK, no APK upload.
3. After install, require `dumpsys`/ActivityManager evidence that `org.pkforge.app.debug` is the resumed foreground Activity, not merely a surviving PID. Run synthetic picker cancellation and provider-read-only tests; keep real provider, QR rotation, backup/restore and independent desktop fixture gates open until separately executed.
