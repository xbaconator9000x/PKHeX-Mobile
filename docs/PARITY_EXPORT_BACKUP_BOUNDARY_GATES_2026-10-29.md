## Implementer notes

- Test the *actual adapted PKForge checkout* after the full ordered scripts, not a synthetic project with only a mocked picker. `ExportModifiedSaveAsync` is a **page method**, not one of the guarded `BoxBrowserViewModel` mutations.
- Source-level and synthetic gates can be fast; API 30/31+ backup/restore and share-sheet checks require real emulator/device evidence. Mark skipped/unsupported as pending, not success.
- A separate `org.pkforge.app.debug` package prevents production PKForge app-private data collision but **does not** prevent Android Auto Backup of the diagnostic app's own files.
- A cache file is not a durable, independently validated Save As destination. A user-initiated share is not an original-URI write, but it can still disclose or distribute unvalidated data.
- Backup privacy and media redistribution rights are independent gates. No self-attested rights approval or “APK ZIP inspected” shortcut.
