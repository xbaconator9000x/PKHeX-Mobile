## Critical source traces

**Cancel is not a transaction in MAUI.** Gen6 record changes call the live setter from an input callback ([M:TrainerEditor6.xaml.cs:79-97](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen6/TrainerEditor6.xaml.cs#L79-L97)); Gen6 fashion uses TwoWay binding against live data ([M:TrainerEditor6Appearance.xaml.cs:19-45](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen6/TrainerEditor6Appearance.xaml.cs#L19-L45)). Gen9 Max buttons and bulk world-state operations mutate the global or captured save before the Save tab ([M:TrainerEditor9.xaml.cs:32-40](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9.xaml.cs#L32-L40), [M:TrainerEditor9Misc.xaml.cs:147-159](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9Misc.xaml.cs#L147-L159), [M:TrainerEditor9Blueberry.xaml.cs:18-41](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9Blueberry.xaml.cs#L18-L41)). In contrast, desktop trainer editors clone the input and only commit on Save ([C:SAV_Trainer9.cs:18-23](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.WinForms/Subforms/Save%20Editors/Gen9/SAV_Trainer9.cs#L18-L23), [C:SAV_Trainer9.cs:181-192](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.WinForms/Subforms/Save%20Editors/Gen9/SAV_Trainer9.cs#L181-L192)). These are deterministic source paths, not device-reproduced losses.

**Document identity can split across tabs.** Gen9 trainer reads/writes global `MainPage.sav` ([M:TrainerEditor9.xaml.cs:41-63](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9.xaml.cs#L41-L63)), while Misc and Blueberry capture a save at construction ([M:TrainerEditor9Misc.xaml.cs:6-15](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9Misc.xaml.cs#L6-L15), [M:TrainerEditor9Blueberry.xaml.cs:5-15](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/SaveEditors/TrainerEditors/gen9/TrainerEditor9Blueberry.xaml.cs#L5-L15)). A stale modal could mix saves after a document replacement. Require a document token on every operation.

**Core setters are not general-purpose safe edits.** `RecordBlock6.SetRecord` has no negative-value guard ([C:RecordBlock6.cs:30-49](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.Core/Saves/Substructures/Gen6/RecordBlock6.cs#L30-L49)); `EventBlockDiff` compares unequal arrays without length validation ([C:EventWorkDiff.cs:78-101](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.Core/Editing/Saves/Editors/EventWork/Diff/EventWorkDiff.cs#L78-L101)); `SplitEventEditor.Save` writes all labeled entries, not only changed ones ([C:SplitEventEditor.cs:44-65](https://github.com/kwsch/PKHeX/blob/7e26bc53215e4f7bc0041ca375f1042539cb81b3/PKHeX.Core/Editing/Saves/Editors/EventWork/SplitEventEditor.cs#L44-L65)). Never expose them as unrestricted mobile mutation commands.
