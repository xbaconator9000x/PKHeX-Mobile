## Architecture, licences and interoperability

Retain exact PKHeX.Core 26.10.18 pin as engine of record. Read-only inspection must not call PID, egg, form or shiny mutators. Add detached raw identity, ability-slot, date, location and form-argument fields; edit only a private clone with document+slot fingerprint and a complete before/after diff. PKForge's layered architecture is useful, but its write-before-form-validation path is not safe to copy. MAUI's shared mutable PKM handlers are not a transactional draft model.

Future PokéBacon profiles require versioned, independently authenticated save layouts and custom species/form/ability/item mappings. A vanilla-looking checksum, filename or successful Core parse never authorizes CFRU/Unbound/Shattered writes; unknown variants remain read-only.

PKHeX.Core declares GPL-3.0-or-later; this project declares GPL-3.0-only. Preserve compatible copyright and GPL notices for any future code reuse. PKForge, MAUI, fonts, sprites and icons require separate rights review. This pass copied no code, assets, ROMs, saves, secrets or conversations.
