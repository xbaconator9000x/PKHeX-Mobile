## Fastest implementation batches (implementation stream owns all code)

**Batch A — offline/rights-neutral preview:** RM-01–12, RM-14 and RM-15. Keep existing PKForge UI + official Core + immutable provider-origin preview. Disable runtime downloads and installer centrally, replace unreviewed bundled media, preserve all write denials. Run local synthetic HTTP and installer spies **before** costly Android compile. A successful diagnostic build is not distribution approval.

**Batch B — reproducible artifact/device:** RM-13, RM-16, then the rights-approved preview-only APK. Require actual Android package install/launch, not a mocked APK manifest. Preserve source and asset hashes, notices and no-secrets discipline.

**Batch C — safe editing:** RM-17 then RM-18, independently tested. RM-19 is a living parity ledger, not a reason to delay A/B or to claim complete desktop functionality.

**No work in this audit modified `app/`, `src/`, `tests/`, dependencies, workflows or README.** No code tests in this document were executed; CI links above cover earlier implementation behavior only. Preserve first README line `# This is a test.`, GPL, and exclusion of ROMs, personal saves, media binaries and secrets.
