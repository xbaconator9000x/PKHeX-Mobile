## Harness to reuse (not rewrite)

Use the existing [SaveInputSnapshot.ReadAsync](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/932feafa2b0350691520d4e8a9dcb06cae9c94ef/src/PKHeXMobile.Domain/SaveInputSnapshot.cs), [SaveDocumentSession.OpenWithIdentityAsync / VerifySourceUnchangedAsync](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/932feafa2b0350691520d4e8a9dcb06cae9c94ef/src/PKHeXMobile.Domain/SaveDocumentSession.cs), [ReadOnlyDocumentService](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/932feafa2b0350691520d4e8a9dcb06cae9c94ef/src/PKHeXMobile.ReadOnly/ReadOnlyDocumentService.cs), [SafReadStream](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/932feafa2b0350691520d4e8a9dcb06cae9c94ef/src/PKHeXMobile.Android/SafReadStream.cs), and [detached PKForge nickname editor](https://github.com/xbaconator9000x/PKHeX-Mobile/blob/932feafa2b0350691520d4e8a9dcb06cae9c94ef/src/PKHeXMobile.PortConsolidation/DetachedRetailNicknameEditor.cs). Bind them to the pinned [PKForge SaveSessionService](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.Infrastructure/SaveSessionService.cs), [AndroidSafFileAccess](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Platforms/Android/AndroidSafFileAccess.cs), and [AndroidDocumentPicker](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/Platforms/Android/AndroidDocumentPicker.cs) through a narrow adapter.

Harness requirements: deterministic fake SAF provider with independent stream opens, controllable identity/bytes/cancellation, open/write counters, permission flags, fault injection, and a session-generation counter. Synthetic saves only in repository; user-consented private fixtures may run locally but must never be committed or logged. Keep the original write barriers from PRs #50 and #52. Distinguish portable tests, Android instrumentation and desktop-matched fixtures in the report.

## P0: source-read and preview correctness (implement first)

| ID | Setup/action | Required assertion and evidence |
| --- | --- | --- |
| PB-01 bounded source | Provider advertises arbitrary length or no length; streams exactly 32 MiB then another byte. Repeat with non-seekable chunked stream. | Adapter refuses the 32 MiB + 1 byte input before PKForge engine activation, caps memory and closes both stream/descriptor; no writes, no session replacement. Exact 32 MiB behavior is separately asserted against current configured limit. |
| PB-02 independent opens | First provider open returns A; second returns B with same opaque identity and one changed byte. | Refuse promotion; old CurrentSession and UI remain intact or are explicitly cleared, never display B as A. Assert two *separate* opens and byte equality requirement. |
| PB-03 identity swap | Both opens return identical bytes but different authority/document IDs; also test identity present then absent. | Refuse promotion. Identity hint alone cannot authorize writes, but identity disagreement must fail. |
| PB-04 stable source | Two independent opens return same bounded synthetic retail fixture and same identity; parse with official Core 26.10.18. | Promote a session only after both opens complete and pass; retain private immutable original fingerprint and selection generation; assert zero provider writes. A passing synthetic fixture is not real retail format certification. |
| PB-05 cancellation during read | Cancel after first stream, during second stream, and before a blocking provider open completes. Include provider that ignores cancellation. | Never activate a cancelled new session, never leak a descriptor or leave a stale loading UI. Record provider cancellation limitations; use bounded timeout in instrumentation, do not claim all providers respond to CancellationSignal. |
| PB-06 source revocation | Revoke read grant or return I/O error on second open; repeat after a successful preview but before next preview. | Reject/clear source-bound preview, show explicit access error, no stale candidate, zero write calls. |
| PB-07 detached source fidelity | Construct a session whose Serialize output differs from its immutable original bytes (without any user edit); trigger nickname preview. | Preview input must equal the original provider snapshot, not session.Serialize output. If parser normalization prevents unchanged round-trip, refuse rather than silently adopting normalized bytes. |
| PB-08 stale preview switch | Open A, start preview, select B before completion; repeat with A replaced by different bytes under same URI. | A's late result never appears under B; generation + fingerprint recheck reject. Cancel/discard cannot mutate either live session. |
| PB-09 session rollback | Trigger every currently disabled SaveEdit, RunMutation, BeginCarry, Drop and gamepad/keyboard entry in the real adapted ViewModel, not only text-transform tests. | Serialize and exported slots remain equal to the immutable baseline, no pending carry or mutation generation, zero writer and provider writes. Prove against actual MAUI ViewModel or closest runnable extracted harness. |
| PB-10 retail/hack discriminator | Feed authenticated positive retail fixture and valid-looking CFRU/Radical Red/Unbound lookalikes of the same size; test both normal and trimmed/container routes. | Only verified retail profile may advance toward editing; known hacks and ambiguous layouts remain preview-only/refused. Negative-only malformed synthetic tests do not satisfy this gate. |

## P1: picker and provider lifecycle (before device claim)

| ID | Setup/action | Required assertion and evidence |
| --- | --- | --- |
| PB-11 pre-cancelled picker | Invoke PickSaveAsync with a token already cancelled before registration; instrument intent starts. | No Android picker launched, no null dereference, task cancellation reported once, _pending cleaned up. The pinned picker currently registers cancellation before returning _pending.Task; this is a source-level risk. |
| PB-12 late picker result | Cancel A after launching picker, open B, deliver A's result late, then B's. | A never satisfies B, no stale URI/grant/session; no double completion or callback leak. |
| PB-13 read-once fallback | Provider grants read but not persistable permission, or throws on TakePersistableUriPermission; then returns a readable stream. | Explicit policy: either allow a one-time bounded read without persisted permission or reject with clear reason; never request/persist write grants. Cover single and multi-select separately. |
| PB-14 Android providers | Instrument on Android with local DocumentsProvider and at least one independent provider; pick, cancel, background/resume, revoke grant, and switch documents. | Record OS/API level, provider, app version, logs with no private bytes, opened descriptor count, and zero original writes. CI MAUI compilation alone cannot pass this. |

## P0: detached Save As prerequisite gates (must remain disabled until proven)

| ID | Setup/action | Required assertion and evidence |
| --- | --- | --- |
| PB-15 source/destination alias | ACTION_CREATE_DOCUMENT returns source URI itself, different URI string with same authority/document ID, or provider-reported ambiguous alias. | Refuse without opening a writable descriptor. No fallback to PKForge's original rwt path. A URI-string inequality alone is insufficient. |
| PB-16 candidate and scope | Valid retail fixture, one detached nickname edit; separately provide malformed, changed-outside-slot and checksum-invalid candidates. | Positive candidate survives official-Core reopen and independent version-specific byte-scope/checksum audit; every negative is rejected before destination write. Existing PKForge CheckWriteSafety alone is not independent layout authentication. |
| PB-17 source race and partial output | Source changes between validation and publication; provider throws mid-destination write, returns short write or readback mismatch. | Refuse stale source; preserve source bytes; never claim successful Save As on partial destination. Report whether destination cleanup is possible; no unsafe overwrite/retry of original. |
| PB-18 successful distinct Save As | Positive authenticated retail fixture, separate writable destination, independent source re-read before/after, candidate write, destination readback. | Original source remains byte-exact and read-only; destination equals validated candidate; reopened save matches requested edit and unchanged fields; receipt includes fingerprints and destination identity. Repeat on actual providers before enabling export. |

## Gates that remain **unexecuted** at this audit

- PB-01 through PB-18: **0/18 executed or certified by this audit**. These are requirements, not passing results. PR #52 already proved source-level grant transformation and writer denial in portable smoke, so do not count those as PB-01–PB-18.
- Do not treat a CI green badge as an Android launch. The compatibility probe intentionally uses a temporary upstream checkout; the production PKHeX Mobile Android UI remains a separate read-only prototype.
- Authentic positive retail save fixtures, desktop PKHeX comparisons, valid-looking hack negatives, provider instrumentation and a safe destination writer are still absent from the evidence reviewed.
- PKHeX MAUI's [pinned project](https://github.com/santacrab2/PKHeXMAUI/blob/a6f7cfb78e1c96155baa67660fd7ae97895e375f/PKHeX.MAUI.csproj) references Core 26.7.7 and separate AutoMod/Injection DLLs. Do not add its editors to the release path until source, dependency and asset rights are resolved. PKForge's [project](https://github.com/sofianeelhor/PKForge/blob/2df04430e532b78c247f45b936f3068d8f824987/src/PKForge.App/PKForge.App.csproj) bundles separately attributed sprites/artwork; reuse source code only under verified compatible licence and attribution.

Publish an Android debug build only after actual launch/provider evidence; do not enable Save As until PB-10 and PB-15–PB-18 also pass for each claimed retail format.

**Owner split:** audit may change only docs/UPSTREAM_* and docs/PARITY_*; implementation owns source/tests/CI/dependencies/README. Preserve README first line "# This is a test.", GPL compliance, and no ROMs, private saves, signing keys or transcripts. The 30 productive-hour target is aspirational, not evidence of completion.
