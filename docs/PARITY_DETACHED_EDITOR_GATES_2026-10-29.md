## High-value implementation tickets: P0 first

**Common test contract:** use only generated synthetic or private consented fixtures outside Git. Record Core NuGet **[26.10.18]**, pinned PKForge `2df04430e532b78c247f45b936f3068d8f824987`, official release source `bfe89c74a3f5265805e364b79bc04ad38ebbc5ea`, fixture recipe, original/candidate SHA-256, generation, expected modified slot and observed result. A green compile or invalid-input refusal does not authorize publishing.

## Handoff and sequencing

**First:** E01 + E03 + E04 + E09 (one detached, visible edit; no publishing). **Second:** E02 + E05 + E06 (authenticate sources and claimed profiles). **Third:** E07 + E08 (safe distinct-document Save As). **Then:** E10–E14 and broader screens. Each completed gate needs CI/job URL, exact commit, test name, fixture recipe and status; unexecuted tests stay **NOT RUN**.

The 30 productive-hour delivery target is aspirational. Keep unknown ROM hacks read-only, never enable original-URI `rwt` writes, and do not report full desktop PKHeX parity from these limited gates. Audit writes documentation only; implementation agent owns code, scripts, tests, app, workflow and dependency changes.
