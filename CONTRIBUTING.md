# Contribution requirements

This project aims at full, verified Android PKHeX parity. A hex inspector, Pokémon mockup or untested save writer is not a completed feature.

Every save-format change requires supported fixtures, negative tests, upstream source references and round-trip evidence. Never modify original saves merely by inspecting. Use explicit compatibility checks, backups, staged writes and recovery.

PRs should explain the affected games/formats, before/after expectations, licence/source provenance, test results, unresolved risks and feature-parity status.

Do not submit ROMs, user saves, console keys, app signing keys or copyrighted artwork. Use synthetic lawful fixtures and hashes where possible.
