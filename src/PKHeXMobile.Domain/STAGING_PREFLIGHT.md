# Staged candidate preflight (read-only, no publication)

This Domain-layer rehearsal composes the existing scoped candidate audit with two independent reads each of an **already created** original-byte backup and staged candidate. Both artifacts must report stable opaque document identities, distinct from the source and each other. The source is freshly reopened and compared **before** and **after** both artifact verifications; same-byte changes of a reported identity are rejected, and changed bytes are rejected even when identity is unchanged. Each stream is disposed after use.

The only inputs are immutable snapshots, candidate bytes, approved byte ranges, and **read-only** provider delegates. There is no writer, Save As implementation, in-place overwrite, rollback, serialization, game-format authorization, or Android SAF publication code. The evidence is non-publishing and intentionally cannot be promoted to a save-write capability. A stable provider key/document key is not a trusted revision or durable storage proof.

The source of approved ranges remains a critical external prerequisite: only independently verified game/layout revisions with same-version desktop PKHeX fixtures may define them. The preflight does not verify semantic edits, PKHeX.Core checksums, raw game identity, unknown ROM-hack data, backup restoration, filesystem fsync, atomic rename, or recovery after interruption. **No production writes may be enabled based on these tests.**

Synthetic regression coverage includes changed bytes on the final source read, same-byte identity swaps, aliasing backup/source/stage documents, absent/changing artifact identities, malformed scopes, corrupt or truncated second artifact reads, cancellation, provider exceptions, stream disposal and an all-valid rehearsal. These are not Android device or independently baselined desktop tests.

This is an independent, clean-room safety composition informed by the source-only findings in `docs/UPSTREAM_IO_BANK_REVIEW_2026-10-28.md` (especially P0-IO-01 and P0-IO-03), `docs/PARITY_IO_BANK_GATES_2026-10-28.md` (S-03/S-04/S-06/S-07 and B-05), and `docs/PARITY_ANDROID_FOLLOWUP_GATES_2026-10-28.md`. No PKForge, MAUI, commercial artwork or game code was copied. Future adoption of upstream UI/editor components must preserve their original notices, the repository's GPL obligations, and the independent safety boundary.
